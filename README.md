# Ashen Road — Пепельный Тракт

Godot 4.3. Бой идёт **в 3D на пепельном тракте**: отряд и враги стоят рядами, бьют с выпадом, камера смотрит на поле. Меню Приюта — обычные экраны.

Вам **не нужен Godot** на компьютере. Сборку Windows делает GitHub.

## Как скачать exe

1. Откройте вкладку **Actions** в этом репозитории.
2. Выберите последний прогон **«Собрать Windows exe»** (зелёная галочка).
3. Внизу справа — **Artifacts → AshenRoad-Windows**.
4. Скачайте zip, распакуйте, запустите `AshenRoad.exe`.

Windows может показать SmartScreen (сборка не подписана). «Подробнее» → «Выполнить в любом случае».

Ручной запуск сборки: Actions → «Собрать Windows exe» → **Run workflow**.

## Бой

- Ряд 1 ближе к центру тракта, ряд 4 — сзади.
- Выберите способность внизу, затем **кликните по фигуре** на поле.
- Тлеющий контур — допустимая цель, золотой — чей ход.
- Удар — выпад в 3D. Смерть — падение.

## Управление

Мышь. Русский интерфейс. Сохранение — в папке данных пользователя Godot.
